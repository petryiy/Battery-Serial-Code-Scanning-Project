# Battery-Serial-Code-Scanning-Project
A project to enhances the traceability and sustainability tracking of battery packs by scanning individual battery cells' serial codes. Each serial code contains important information, including the manufacturing date and embodied carbon footprint. The software will log this data and associate it with a battery pack-level serial, enabling live carbon calculations and tracking of each battery cell's lifecycle status globally.

Objectives

Data Capture: Develop a scanning mechanism to read battery serial codes efficiently.

Information Extraction: Extract data related to the manufacturing date and embodied carbon from the serial codes.

Database Integration: Create a database to log and store serial information along with associated battery pack-level data.

Carbon Calculation: Implement a feature to calculate the cumulative carbon impact of individual battery cells and packs over their lifecycle.

Global Tracking: Ensure that the system allows for real-time tracking of battery cells and packs, regardless of their location.
